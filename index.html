راه‌حل

بخش‌هایی از API (API Endpoints)

  • POST /api/accounts/: ایجاد یا ثبت‌نام کاربر جدید.
  • POST /api/accounts/login/: ورود کاربران.
  • POST /api/accounts/logout/: خروج کاربران.
  • GET /api/operations/: دریافت لیست عملیات موجود.
  • POST /api/operations/: ایجاد عملیات جدید (مثلاً تحلیل یا محاسبه).
  • GET /api/operations/{id}/: دریافت جزئیات عملیات مشخص با شناسه id.

مسیرهای صفحات وب (Web Pages)

  • GET /accounts/login/: صفحه ورود کاربران.
  • GET /accounts/profile/: صفحه داشبورد پس از ورود کاربران.
  • GET /operations/new/: فرم ایجاد عملیات جدید.
  • GET /operations/history/: نمایش تاریخچه عملیات کاربر.
  • GET /operations/detail/{pk}/: مشاهده جزئیات عملیات مشخص با شناسه pk.
  • GET /operations/download/{pk}/: دانلود نتیجه عملیات با شناسه pk.

سیستم بر پایه Django REST Framework ساخته شده و از Django Channels برای ارتباطات بلادرنگ (Real-time) استفاده می‌کند. پایگاه داده MySQL برای ذخیره‌سازی اطلاعات به کار رفته است.

بخش‌هایی از API

  • POST /api/surveys: ایجاد یک نظرسنجی جدید.
  • POST /api/surveys/{id}/responses: ثبت پاسخ به یک نظرسنجی.

  • دسترسی به اطلاعات صاحب دستگاه

  • امکان افزودن و حذف دستگاه‌ها
  • قابلیت تغییر وضعیت دستگاه‌ها
  • دسترسی به تصاویر و پرداخت‌های هر دستگاه

توضیحات API

  • admin-dashboard/: نمایش داشبورد مدیریتی برای ادمین‌ها
  • search-devices/: جستجوی دستگاه‌ها بر اساس معیارهای مختلف
  • get-notifications/: دریافت اعلان‌ها و نوتیفیکیشن‌های سیستم
  • add-device/: افزودن دستگاه جدید به سیستم
  • delete-device/: حذف دستگاه از سیستم
  • toggle-device-status/: تغییر وضعیت فعال/غیرفعال دستگاه
  • get-device-details/<device_id>/: دریافت جزئیات کامل یک دستگاه
  • get-device-images/<device_id>/: دریافت تصاویر مرتبط با یک دستگاه
  • get-device-payments/<device_id>/: دریافت اطلاعات پرداخت‌های یک دستگاه
  • device-profile/<device_id>/: نمایش پروفایل کامل دستگاه

تکنولوژی‌های استفاده شده

  • Back-End: Django, Django REST Framework
  • پایگاه داده: SQLite
  • Front-End: HTML, CSS, Bootstrap, JavaScript
  • ارتباطات: REST API , MQTT

مستندات سرور ارسال فایل لوکال (LAN File Share Tool)

×

معرفی کلی

این ابزار با استفاده از ماژول‌های داخلی Python (http.server، socket، threading، tkinter) ساخته شده است و امکان به اشتراک‌گذاری فایل‌ها و پوشه‌ها در شبکه محلی (LAN) را بدون نیاز به نصب نرم‌افزار اضافی فراهم می‌کند.

ویژگی‌های اصلی

  • حالت گرافیکی (GUI): انتخاب آسان پوشه یا فایل، نمایش آدرس دانلود، شروع/توقف سرور با یک کلیک.
  • حالت خط فرمان (CLI): اجرای سریع با پارامترهای --dir، --file و --port برای استفاده در سرورهای بدون رابط کاربری.
  • پشتیبانی از اشتراک فایل تکی: با انتخاب یک فایل، فقط همان فایل در دسترس دانلود قرار می‌گیرد.
  • تشخیص خودکار IP محلی: نمایش آدرس صحیح برای اتصال سایر دستگاه‌ها.
  • قابلیت تغییر پورت: امکان اجرا روی هر پورت دلخواه (پیش‌فرض 8000).
  • پایدار و چندنخی: سرور در یک نخ جداگانه اجرا می‌شود تا رابط کاربری قفل نشود.

نحوه استفاده (GUI)

  1. نوع اشتراک (پوشه یا فایل تکی) را انتخاب کنید.
  2. دکمه Select را بزنید و مسیر مورد نظر را مشخص کنید.
  3. در صورت نیاز، شماره پورت را تغییر دهید.
  4. روی Start Server کلیک کنید.
  5. آدرس نشان داده شده (مثلاً http://192.168.1.5:8000) را در مرورگر دستگاه دیگر وارد کنید.
  6. برای توقف سرور، دکمه Stop Server را بزنید.

حالت خط فرمان (CLI)

python file_share.py --dir /path/to/folder --port 8080
python file_share.py --file document.pdf --port 9000

نیازمندی‌ها

  • Python 3.6 یا بالاتر (بدون نیاز به کتابخانه خارجی)
  • سیستم‌عامل: Windows / Linux / macOS
